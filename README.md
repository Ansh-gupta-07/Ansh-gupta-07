## About

I’m a frontend-leaning full-stack developer interested in building useful products with thoughtful security. I work primarily with React, JavaScript, Python, and Django REST Framework, and enjoy designing authentication and encryption into systems from the start.

Currently building **DevSync**, a platform that helps people find collaborators for projects. I also co-created **HOPE OS / Trust Exam Shield**, an offline exam environment designed for secure, kiosk-mode use.
